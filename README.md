## About Me

I am a computer science student interested in how software architecture, runtime behavior, resource constraints, and distributed coordination affect real systems.

My work currently spans two areas:

- **Systems and distributed computing** — heterogeneous worker metrics, Rust/TCP communication, protocol design, and workload scheduling research.
- **Secure software engineering** — revocation-aware access control, cache revalidation, reproducible experiments, and test coverage.

I enjoy tracing behavior through source code, separating implemented functionality from planned work, and measuring claims with reproducible tests and experiments.

## Current Focus

- Building the metrics and communication foundation for a **distributed LLM fine-tuning scheduler** in Rust.
- Studying heterogeneous worker capacity, CPU/memory constraints, and periodic workload redistribution.
- Improving **revocation-aware RAG access control** in Java and evaluating cached authorization behavior.
- Writing focused JUnit and Python tests, collecting reproducible experiment results, and documenting system behavior.
