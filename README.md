## Featured Projects

**[RAG Revocation Research](https://github.com/seneca-c137/rag-revocation-research)**

A Java prototype that keeps document access decisions current in a simulated RAG pipeline, so a revoked user or role cannot keep access to a cached document.

Stack: `Java 21` · `Maven` · `JUnit 5` · `Jackson` · `Python`

**[Distributed LLM Fine-Tuning Scheduler](https://github.com/seneca-c137/distributed-llm-finetuning-schedule)**

A Rust research project exploring periodic, adaptive workload redistribution across heterogeneous workers to reduce straggler delays at synchronization boundaries.

Stack: `Rust` · `Cargo` · `Python` · `psutil` · `Serde` · `TCP/NDJSON`

## Engineering Practices

- Trace edge cases through source code and reproduce behavior with focused tests.
- Design experiments for cache revalidation, permission transitions, and revocation.
- Write JUnit and Python tests for authorization, retrieval, metadata filtering, caching, and synthetic datasets.
- Export raw observations and reproducibility metadata for repeatable analysis.
- Distinguish implemented functionality from planned architecture and research goals.
- Use Git branches and focused diffs to keep changes reviewable.
